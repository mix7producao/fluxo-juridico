# Publicar no GitHub

O repositório deve ser privado e conter somente instruções e modelos vazios.

## Forma mais simples

1. Entre em <https://github.com/new>.
2. No nome do repositório, escreva `sa-organizacao-casos-ia`.
3. Marque a opção `Private`.
4. Crie o repositório sem adicionar arquivos extras.
5. Copie o endereço HTTPS apresentado pelo GitHub.
6. Nesta pasta, dê dois cliques em `PUBLICAR-NO-GITHUB.cmd`.
7. Cole o endereço quando solicitado e pressione Enter.
8. O navegador poderá pedir que você entre na sua conta do GitHub.

Nas atualizações futuras, dê dois cliques novamente em `PUBLICAR-NO-GITHUB.cmd`. O programa registrará as alterações e enviará a versão nova.

## O que nunca deve ser publicado

- Pasta de caso real.
- PDF de processo.
- Exportação de WhatsApp.
- Áudio, vídeo ou fotografia de cliente.
- Nome, CPF, endereço ou documento pessoal.
- Senha, chave de acesso ou credencial.
