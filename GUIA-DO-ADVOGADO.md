# Guia rápido do advogado

## Abrir um caso novo

1. Crie uma pasta com o nome interno do caso.
2. Coloque nela todos os documentos recebidos.
3. Inclua o PDF integral do processo, se houver.
4. Exporte o WhatsApp com mídias e coloque o ZIP intacto na pasta.
5. Inclua áudios, vídeos, fotografias, contratos, comprovantes, decisões e intimações.
6. Abra a pasta no Codex ou no Claude Code.
7. Escreva: `Quero abrir e organizar um novo caso jurídico.`
8. Leia o lembrete e, quando terminar de enviar tudo, responda `PODE ORGANIZAR`.

## Produzir uma peça

Depois que a organização terminar, escreva:

```text
Analise o caso organizado e produza a peça jurídica adequada em Word. Não invente informações. Antes de concluir, mostre as pendências que dependem de confirmação da advogada.
```

## Regra essencial

Nunca coloque processo, prova ou dado de cliente no GitHub. O link do GitHub serve apenas para instalar as instruções do escritório.
